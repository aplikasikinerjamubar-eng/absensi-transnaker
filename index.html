⚙️ Pengaturan

Konfigurasi tanda tangan dan manajemen user

🚀
Init All (Setup / Perbaikan Sistem Lengkap)
Jalankan ini jika ada sheet/kolom yang belum lengkap, trigger otomatis tidak jalan, atau setelah pembaruan sistem. Aman dijalankan berkali-kali -- tidak akan menduplikasi atau menghapus data yang sudah ada.
✍️
Tanda Tangan Laporan
⏰
Jendela Waktu Absen Mandiri (Individu ASN)
Menentukan rentang jam ASN diperbolehkan melakukan Absen Mandiri sendiri lewat menu Absen Mandiri. Di luar rentang ini, tombol absen akan ditolak sistem dan ASN harus dibantu admin untuk input manual. Pengaturan ini tidak memengaruhi checklist Apel Pagi/Sore yang diisi admin.
🛰️
Titik Koordinat Lokasi Apel (untuk validasi Absen Apel & Hadir)
Koordinat ini dipakai sistem untuk memastikan ASN benar-benar berada di lokasi apel/kantor saat melakukan Absen Apel atau Absen Hadir lewat Absen Mandiri. Wajib diisi & disimpan, jika tidak ASN tidak akan bisa Absen Apel/Hadir. Jika jadwal atau lokasi apel berpindah (mis. dari kantor ke lapangan lain), tentukan ulang titik di peta lalu simpan di sini — perubahan langsung berlaku untuk semua ASN.
Memuat koordinat tersimpan...
🗺️ Cara paling akurat: cari alamat kantor di kolom bawah ini, atau geser peta lalu klik/tap tepat di titik lokasi apel/kantor. Pin akan mengikuti, dan Latitude/Longitude otomatis terisi.
Latitude/Longitude di atas mengikuti pin di peta secara otomatis. Bisa juga diketik manual -- pin di peta akan ikut pindah.
⚡
Provisioning Akun ASN Otomatis
Buat akun login otomatis untuk seluruh ASN berdasarkan data di Data Pegawai. Username = NIP masing-masing ASN, password default = munabaratkab. Sarankan ASN mengganti password setelah login pertama.

Status Khusus ASN (Tugas di Dinas Lain / Cuti)
Tandai ASN yang sedang ditugaskan/dinotatugaskan ke dinas atau instansi lain supaya sistem tidak menandai mereka Alpha secara otomatis setiap hari -- data absen mereka sama sekali tidak akan disentuh/diubah sistem selama status ini aktif. Untuk ASN yang sedang Cuti, sistem otomatis mencatat status Cuti (bukan Alpha) selama tanggal hari ini berada dalam rentang yang diatur di sini. Kosongkan Tanggal Mulai/Selesai jika belum tahu tanggal pastinya -- status akan tetap berlaku sampai dikembalikan Normal secara manual.
